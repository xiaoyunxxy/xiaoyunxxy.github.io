## What this repo is

Personal academic homepage for Xiaoyun Xu (PhD student, Radboud University Nijmegen), built with Jekyll using the [AcadHomepage](https://github.com/RayeRen/acad-homepage.github.io) template. Published at `https://xiaoyunxxy.github.io`.

## Local development

```bash
bash run_server.sh        # starts Jekyll livereload server at http://127.0.0.1:4000
```

This runs `bundle exec jekyll serve`. Changes to source files auto-refresh the browser; changes to `_config.yml` require a server restart.

## Content architecture

All visible page content lives in `_pages/include/` as separate Markdown files:

- `intro.md` — bio / about section
- `news.md` — news items
- `pub.md` — publications list
- `others.md` — miscellaneous (awards, service, etc.)

These are assembled by `_pages/about.md` via `{% include_relative include/... %}`. The about page is the homepage (permalink `/`).

**Publication entries** use a `<div class='paper-box'>` HTML structure with a badge, image, title link, authors, venue, and optional code/arXiv links. Copy an existing entry as a template.

**Google Scholar citation counts** are injected client-side using `<span class='show_paper_citations' data='SCHOLAR_PAPER_ID'>`. The citation data is fetched from the `google-scholar-stats` branch (generated by a GitHub Action that runs `google_scholar_crawler/main.py` using the `GOOGLE_SCHOLAR_ID` secret).

## Site configuration

`_config.yml` controls author info (name, avatar, bio, links), analytics, SEO verification keys, and Jekyll settings. This file is not hot-reloaded — restart the server after editing it.

## Static assets

- `images/` — paper figures and profile photos; referenced directly in `_pages/include/pub.md`
- `cv/xxy_CV.pdf` — CV file
- `thesis/xxy_thesis.pdf` — thesis file
- `_sass/` — SCSS partials; `_sass/_variables.scss` for theme-level style changes
